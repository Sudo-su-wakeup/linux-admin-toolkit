
# Linux Admin Toolkit

A Bash-based Linux administration toolkit built on Amazon Linux 2023 using AWS EC2.

## Features

- System health reporting using `syshealth.sh`
- Memory and swap monitoring
- Disk usage reporting
- CPU and process monitoring
- Interactive terminal menu

## Requirements

- Linux (Amazon Linux 2023)
- Bash
- Standard Linux utilities

## Usage

Make the scripts executable:

```bash
chmod +x admin-toolkit.sh syshealth.sh
```

Run the toolkit:

```bash
./admin-toolkit.sh
```
